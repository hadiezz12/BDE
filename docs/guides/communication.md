# Guide : communication d'une asso

Ton poste te donne des droits sur les **Contenus**, les **Médias** et parfois
les **Messages** de l'asso, jusqu'à la date de fin de ton mandat.

- **Écrire un article** : Contenus › Nouvel article, puis « Soumettre à
  relecture » si ton asso relit avant publication. Une version soumise est
  figée : l'approbation porte sur cette version exacte.
- **Programmer** : une publication approuvée part à l'heure prévue, même si
  tu as quitté l'équipe entre-temps. Le site vérifie au moment de publier que
  rien ne l'empêche (contenu masqué, asso suspendue).
- **Médias** : images de l'asso. Jamais la photo d'une personne sans son
  accord.

## Avant de partir (liste de passation, domaine Communication)

1. Les articles en attente de relecture sont traités ou confiés.
2. Les publications programmées sont vérifiées.
3. La médiathèque est revue.
4. Les relectures sont confiées à l'équipe qui arrive.

Ces points se cochent dans **Passation** par les personnes qui ont le droit
d'approuver les articles. Tu ne donnes jamais ton mot de passe : la personne
qui arrive reçoit un poste avec ses droits, c'est tout.
