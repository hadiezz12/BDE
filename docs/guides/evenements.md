# Guide : événements d'une asso

Ton poste te donne des droits sur les **Événements** de l'asso (créer,
modifier, publier, gérer les inscriptions selon ce que la présidence a
donné), jusqu'à la date de fin de ton mandat.

- Les places sont comptées par la base de données : pas de double
  inscription, la liste d'attente avance seule quand une place se libère.
- Les inscrit·es reçoivent un rappel la veille, automatiquement.
- Annuler un événement prévient les inscrit·es.
- Tu vois les noms des participant·es seulement si ton poste a ce droit ;
  jamais leurs adresses.

## Avant de partir (liste de passation, domaine Événements)

1. Les événements à venir sont revus.
2. La gestion des inscriptions est confiée à quelqu'un qui reste.
3. Les rappels sont vérifiés.
4. Qui annule ou prévient en cas d'imprévu est décidé.

Les inscriptions restent après ton départ : l'événement appartient à l'asso,
pas à toi.
